# YesONO 3.0 · Fintech Motion System

## Palette
- Ink `#0A101C` ground
- Brass `#D4B36A` titles / stamps / CTA
- Harbor `#6FA3DC` grids / links / secondary
- Jade `#6FC2A0` trust / chain / verified
- Alert `#E85D5D` risk pulse (clip 02 only)
- Text `#E8EEF7` / dim `#AEBED2`

## Typography
- Display Chinese: Songti SC / STSong / Noto Serif CJK SC
- UI Chinese: PingFang SC
- Labels / codes: JetBrains Mono (or ui-monospace)

## Motion law
- 4 shots per clip matching script beats; **hard cut or 60–90ms white flash** between shots
- Camera: slight push-in / pull-out / parallax on ground grid
- Overshoot on card pop-ins; stamp hits; depth bars grow from bottom
- No slow dissolves except final CTA fade
- Dense tech feel: grid light-up, particle/data ticks, glow pulses — restrained, not carnival

## Safe areas
- Captions bottom third, keep 120px from edges
- Hero type centered or left 96px gutter
