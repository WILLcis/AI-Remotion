版本 B · 分镜脚本(约 70 秒)
镜头 1(0-8s) 画面:一个人类头像周围,逐渐聚集出十几、几十个 agent 头像,画面逐渐拥挤
旁白:"当 AI 同事的数量,是人类同事的十倍、二十倍——协同要怎么跑?"
镜头 2(8-18s) 画面:同一张任务卡在人类头像和 agent 头像之间自由流转,拖拽、指派、评论,动作完全一致
旁白:"人和 AI 不是两套系统。在 BIOS 里,agent 和人类共享同一套工作对象——能被指派、能建单、能评论、能推进状态。AI 是正式成员,不是外挂的机器人。"
镜头 3(18-30s) 画面:一个 agent 节点向下分叉出多个子 agent 节点(委派树),但每条线最终都收束回一个人类头像
旁白:"数量越多,问责越不能丢。委派可以一层层级联,但每一层都归属并问责于一个具体的人,权限不会失控上升。"
镜头 4(30-42s) 画面:控制塔俯瞰视角,密密麻麻的任务流突然收束成一个清爽的仪表盘,红色卡点自动上浮
旁白:"人不该去逐个盯几百个 agent。BIOS 是一座控制塔——一屏看清全公司谁在干什么、卡在哪,该升级的自动冒泡,该消化的留在部门内。"
镜头 5(42-52s) 画面:一份 AI 产出被推向一道"验证门"图标,通过后才变绿、才能关闭
旁白:"产出再多,也绕不过验证。无验证,不完成。"
镜头 6(52-62s) 画面:每个 agent 头像外围有一圈虚线边界(仓库/密钥/额度图标),边界始终清晰,不随数量扩张而模糊
旁白:"规模翻十倍,边界不会松一寸——每个 agent 只能碰它被批准的资源。"
镜头 7(62-70s) 画面:Logo 定格,背景是人类与 agent 头像有序排布在同一个操作系统界面里
旁白:"BIOS——让十倍以上的 AI 同事,和人类同事,在同一套规则里安全协同。"
