# AI-Remotion HyperFrames 产品宣传片分镜

参考视频的可复用原则：近方形舞台、深色颗粒背景、抽象柔边渐变形状、强标题层级、单一内容焦点和卡片式切换。成片使用全新的文案、图形、演示界面与节奏。

| 时间 | 画面 | 屏幕文案 |
| --- | --- | --- |
| 0–10 秒 | 抽象渐变背景与产品标题 | 把想法变成成片。 |
| 10–20 秒 | 痛点标题切换 | 写、画、配、剪不用来回切换。 |
| 20–30 秒 | 原创的演示界面 mockup | 今天要讲什么？ |
| 30–40 秒 | 真实 CLI 命令语义的终端动效 | 脚本、配音、渲染依次就绪。 |
| 40–50 秒 | 审阅与可控性价值 | 每一份脚本、每一个镜头都可审阅。 |
| 50–60 秒 | 品牌式 CTA | 从 brief 到发布前 QA。 |

所有界面均标注“演示界面”，仅用于说明项目中已存在的 CLI/产物工作流，不代表浏览器 UI 已上线。
