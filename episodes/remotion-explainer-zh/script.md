# 普通人怎么理解 Remotion

## Segment 1
Spoken: 做视频，能像写代码一样灵活吗？这就是 Remotion。
Visual: 深色背景，标题「Remotion是什么？」渐显，左侧代码图标与右侧视频图标慢慢合在一起。
Duration: 5秒

## Segment 2
Spoken: Remotion 用 React 写代码生成视频，不是剪辑软件。
Visual: 信息卡片「用 React 写代码 → 生成视频」，旁边出现一个带红叉的「剪辑软件」图标。
Duration: 5秒

## Segment 3
Spoken: 核心思路一：组件即画面。每个画面都是可拼装的积木。
Visual: 深色背景上出现「组件 = 画面」卡片，三块积木拼成一个视频窗口，积木微微浮动。
Duration: 5秒

## Segment 4
Spoken: 核心思路二：帧由时间驱动。想改哪一帧，改代码就行。
Visual: 时间轴从左向右移动，指针路过每一帧时，对应画面随之变化，强调指针与画面的联动。
Duration: 5秒

## Segment 5
Spoken: 核心思路三：可程序化批量产出。换参数，就能生成一批视频。
Visual: 展示三张参数卡片，数值不同，点击「生成」后下方出现一排视频文件图标，文件依次排列。
Duration: 5秒

## Segment 6
Spoken: 对普通人来说，做视频变成改参数、写代码，可复用、可版本管理。
Visual: 画面上方显示「改参数」滑块，下方出现代码分支图，代表版本管理；最后定格在「Remotion」Logo上。
Duration: 5秒
